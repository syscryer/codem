# Task: 工作流管理卡片原型

## Background

当前工作流原型只有画布内的 Mock 保存反馈，用户无法从管理入口查看已保存工作流，也无法重新打开继续编辑。需要补充一个轻量的工作流管理页，验证“保存 -> 卡片 -> 重新编辑”的闭环。

## Objective

让工作流可在前端 Mock 中保存到管理页，并以卡片形式展示、搜索、筛选、复制和重新打开编辑。

## Scope

In scope:

- Agent Hub 的工作流标签默认展示工作流管理页。
- 使用 Mock 数据展示已保存工作流卡片，支持搜索、状态筛选、打开编辑、复制和新建。
- 编辑器支持返回管理页、编辑工作流名称，并将保存结果更新回当前页面的管理卡片。
- 复用现有工作流画布、节点、连线和多轮讨论配置。

Out of scope:

- 不接 SQLite、后端 API、真实运行历史或跨刷新持久化。
- 不实现发布流程、权限、删除确认、版本历史和协作编辑。

## Impact

- frontend：修改工作流 Mock 数据、画布入口和工作流局部样式；无 backend、网络和隐私影响。

## Acceptance Criteria

- [x] 工作流标签默认进入管理页，并以卡片展示 Mock 已保存工作流。
- [x] 卡片显示名称、摘要、状态、更新时间和节点/Agent 概览。
- [x] 用户可搜索、按状态筛选、打开编辑、复制和新建工作流。
- [x] 编辑器保存后更新对应卡片；未保存修改返回管理页时不会静默丢失。
- [x] 刷新页面恢复初始 Mock 数据，页面明确保持 Mock 边界。
- [x] 类型检查、针对性测试、生产构建、差异检查和双视口浏览器验收通过。
